# GharPlate Data Directory (`data/`)

This directory houses the reproducible data pipeline artifacts for GharPlate:

- `data/raw/`: Staging directory for raw reference tables or CSV/JSON extracts prior to normalisation.
- `data/processed/catalog_manifest.json`: Normalised catalog manifest generated by `scripts/seed_data.py`.
- `data/import_reports/latest_import_report.json`: Automated ingestion verification report recording source counts, food counts, multilingual alias counts, known nutrient values, and explicit `NULL` unmeasured nutrient counts (`zero_replacement_for_missing: false`).

## Running the Ingestion Pipeline

```bash
python3 scripts/seed_data.py
```
